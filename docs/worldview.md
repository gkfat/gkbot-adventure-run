# GkBot Adventure Run 世界觀

> 本文件是內部設計參考文件，供後續 openspec change（`adventure-run-core`、`events-and-blessings`、`items-and-equipment`、`combat-engine`、`redesign-character-archetypes` 等）撰寫敘事文案、道具/怪物命名時對齊使用。
>
> **可公開／玩家可見**：GK 宇宙時間線、GkBot 浩劫、裂域＝GK 公司各類設施——這些是遊戲本身可以明講的世界觀背景，適合用在開場旁白、圖鑑、載入畫面等文案。
> **⚠️ 僅限暗示，禁止明講**：玩家角色自身已局部機械化這件事——只能透過道具描述、機制細節（例如「喝機油回血」）讓玩家自己拼湊/懷疑，任何文案都不可以直接寫出「你已經是半機械人」這類明確陳述。

## 1. 世界觀時間線：GK 宇宙與 GkBot 浩劫（可公開）

沿用 `side projects/logicard-duel` 已確立的世界觀時間線（見該專案 `docs/worldview.md`）：

> 公元 5487 年，GK 公司量產的勞力機器人「GkBot」全面普及，某天無預警開始攻擊人類，短時間內地球人口驟減近 70 億，倖存者四散躲藏。

`gkbot-adventure-run` 與 `logicard-duel` 是**同一場浩劫、不同的求生方式**，這點可以直接寫進遊戲的世界觀文案：
- `logicard-duel`：倖存者靠「向 GkBot 發起邏輯牌決鬥」正面對決，賭命求生
- `gkbot-adventure-run`：倖存者組隊反覆深入「裂域」——GK 公司散布各地的舊設施——進行一次次的探索遠征（roguelike run），靠戰鬥、拾荒、意外的機緣存活下來並帶回資源

## 2. 裂域是什麼：GK 公司的各類設施（可公開）

「裂域」不是抽象的異空間，而是**具體、寫實的 GK 公司設施群**，浩劫發生後被廢棄、失控、部分區域甚至因失控系統而扭曲變形，倖存者稱之為「裂域」是因為每個設施內部因失控多年，早已面目全非、詭異難辨：

| 設施類型 | 原本用途 | 裂域化後的樣貌 |
| --- | --- | --- |
| 補給設施 | GK 公司的物流/倉儲中心，存放 GkBot 零件與民生物資 | 自動販賣/補給系統仍在運作但邏輯錯亂，是「商店」「寶箱」節點的主要場景 |
| 研究設施 | 研發 GkBot 與相關量產技術的實驗室 | 殘留的實驗性強化裝置、未知藥劑仍在自動運作，是「祝福（Blessing）」節點的主要場景 |
| 維修設施 | GkBot 的保養/維修中心 | 殘存的維修型 GkBot 與失控機具在此徘徊，是「怪物（Monster）」節點常見場景 |
| 虛擬實境設施 | 原本用於 GkBot 表演型/教育型的模擬訓練場 | 現實與模擬邊界崩壞，環境會出現不合理的扭曲景象，是「輪盤（Roulette）／事件」節點的主要場景，也是「異世界感」最強烈的地方 |

這張對照表可以直接作為未來設計節點視覺風格、場景文案、甚至怪物/道具命名的素材庫——不需要另外發明一套「異世界」美術語言，全部都能合理地從「一間廢棄的 GK 公司設施」長出來。

## 3. 玩家角色的秘密：局部機械化（⚠️ 僅限暗示）

延續 `logicard-duel` 「裝備＝外部工具、卡牌＝身體機械化」的敘事對比，`gkbot-adventure-run` 把這個設定往前推一步：**倖存者在裂域裡進出多次後，身體已經局部機械化，但自己完全沒有意識到這件事**。這件事只能透過**機制與道具文案的細節**讓玩家自己起疑，絕不能有任何文案直接點破。

### 3.1 藥水（機油）—— 最主要的暗示載體

道具圖示與名稱維持「藥水」不變（icon、in-game 顯示名稱都正常呈現為治療類消耗品），但**物品描述文案**要讓玩家自己讀出違和感。範例基調（正式文案可依此發想，不必逐字照搬）：

> 「為什麼我喝機油會補血...？但真好喝，咕嚕咕嚕咕嚕。」

寫作原則：
- 角色**明確感到疑惑**（「為什麼喝機油會有效」），製造認知失調
- 但角色**毫不抗拒、甚至覺得好喝**，暗示身體已經「認得」這種物質，而非單純黑色幽默的硬吞
- 全程不解釋原因，把懸念留給玩家

其他稀有度的藥水可以延伸同一套語氣，例如越高稀有度、角色反應越自然/越上癮（「這瓶...特別香」「怎麼有點想念這個味道」），暗示機械化程度隨劇情/等級推進而加深，但同樣不可明講。

### 3.2 其他可延伸的暗示點（非本次必做，供未來設計參考）

| 遊戲內顯示的樣子 | 暗示手法 |
| --- | --- |
| 商店/拾荒能用零件、螺絲釘之類的雜物交易 | 角色台詞可以是「這種破銅爛鐵他們也收？」但商人真的收了，且給的報酬不差 |
| 工匠 Tinkerer 的核心特色「Salvage」 | 角色描述可以強調他「莫名其妙就是知道怎麼修」，而非「因為他學過工程」——技能來源本身就帶點違和感 |
| 祝福（Blessing）節點的增益 | 效果描述可以是身體的變化感（發熱、震動、金屬味），而不是傳統奇幻的光芒/神聖感 |

## 4. 5 個職業（archetype）在此設定下的重新定位

延續 `character-design.md` 已定案的 5 個職業（沿用其屬性/機制設計，`openspec/changes/redesign-character-archetypes`），世界觀上重新定錨為：他們並非「被傳送到異世界」，而是**同一場末日浩劫下，走上不同求生路線的倖存者**，各自帶著末日前的職業技能踏入裂域討生活：

| 職業 | 末日前身分 | 在裂域裡看似什麼 | 實際上（⚠️ 僅限暗示） |
| --- | --- | --- | --- |
| 戰士 Fighter | 運動員/健身者 | 身體素質最好，最快適應戰鬥 | 機械化程度最淺，單純靠肉身撐過去 |
| 冒險家 Adventurer | 背包客/旅行者 | 擅長探索、常發現隱藏內容 | 憑本能感知到設施裡「不對勁的地方」往往藏著殘存系統的接口 |
| 學者 Scholar | 學生/研究員 | 靠學習/記錄敵人規律取得優勢 | 下意識在拼湊裂域運作邏輯，某種程度上正逼近真相 |
| 工匠 Tinkerer | 工程師/Maker | 靠拾荒零件轉化能力 | **全職業中最接近察覺真相的人**（見 3.2） |
| 投機者 Gambler | 業務/上班族 | 熱愛輪盤、賭博式抉擇 | 純粹的人性本色，與機械化真相無關，作為對照組保留敘事透氣空間 |

Tinkerer 是刻意設計成「敘事上最靠近真相」的角色——如果之後要做角色專屬旁白/隱藏對話，工匠是最適合埋伏筆的職業。

## 5. Roguelike Run 節點的世界觀包裝

一次 run 走 10~15 個節點（`adventure-run-core` 已定案的狀態機骨架），節點類型對應第 2 節的設施類型：

- **戰鬥（Monster）**：主要發生在維修設施，遭遇殘存/失控的維修型 GkBot 與失控機具（外觀可呼應 `logicard-duel` 的工作/表演/侵略/防禦 4 型號分野，後續設計怪物範本時可作為風味參考，不必 1:1 對應）
- **寶箱（Chest）**：主要發生在補給設施，拾荒殘留物資，掉落裝備/道具/零件素材
- **祝福（Blessing）**：主要發生在研究設施，殘留的實驗性強化裝置自動運作，玩家體感是神秘力量賜福
- **輪盤（Roulette）／事件**：主要發生在虛擬實境設施，現實與模擬邊界崩壞下的機緣與風險並存的抉擇點，投機者職業在此節點特別吃香

## 6. 尚待確認 / 可延伸的敘事缺口

- 怪物範本目前尚未實作（`combat-engine`/`adventure-run-core` 尚無怪物資料表），第 5 節的「維修設施殘存 GkBot」只是設定方向，實際命名/圖鑑內容留待對應 change 設計
- 是否要讓 Tinkerer 之外的職業也有機會透過特定劇情/隱藏事件察覺真相（例如 Scholar 的 Study 機制長期累積後），目前沒有機制掛鉤，屬於未來可選的敘事擴充
- `logicard-duel` 侵略型 GkBot 台詞暗示的「秘密」與「自毀程式」尚未定案具體內容；若之後要讓兩個專案的伏筆互相呼應（例如裂域的成因與該秘密相關），需要回頭同步更新兩份世界觀文件
- 3.1 節的機油藥水文案目前只有基調範例，正式上線文案（含各稀有度的漸進式暗示語氣）留待內容撰寫階段定稿
