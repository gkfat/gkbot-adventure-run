# GkBot Adventure Run 世界觀

> 本文件是內部設計參考文件，保留故事性的世界觀基底，供後續 openspec change 撰寫敘事文案、道具/怪物命名時對齊使用。已經落地為具體機制/數值的部分（設施風險分級、怪物範本、道具稀有度文案、職業定位、Run/Stage/節點結構等）改由對應 change 的 spec 承載定案內容，本文件不再重複列出。
>
> **玩家可見**：GK 宇宙時間線、GkBot 浩劫、廢棄 GK 公司各類設施——這些是遊戲本身可以明講的世界觀背景，適合用在開場旁白、圖鑑、載入畫面等文案。
> **僅限暗示**：玩家自身已不再是完整的人類——只能透過道具描述、機制細節（例如「GkBot 零件居然可以強化自己、喝機油居然可以回血」）讓玩家自己拼湊/懷疑，任何文案都不可以直接點明玩家已經發生了什麼事。

## 1. 世界觀時間線：GK 宇宙與 GkBot 浩劫

沿用既有 GK 宇宙已確立的世界觀時間線：

> 公元 5487 年，GK 公司量產的勞力機器人「GkBot」全面普及，某天無預警開始攻擊人類，短時間內地球人口驟減近 70 億，倖存者四散躲藏。

這場浩劫下，倖存者走上了各自不同的求生方式，這點可以直接寫進遊戲的世界觀文案：有人選擇正面對決、賭命一搏；`gkbot-adventure-run` 描寫的則是倖存者孤身一人，反覆深入 GK 公司散布各地的廢棄設施，進行一次次的探索遠征（roguelike run），只為了活下去——靠戰鬥、拾荒、意外的機緣存活下來並帶回資源。

## 2. GK 公司的各類廢棄設施

遊戲裡的探索場景不是抽象的異空間，而是**具體、寫實的 GK 公司設施群**，浩劫發生後被廢棄、失控、部分區域甚至因失控系統而扭曲變形，早已面目全非、詭異難辨。設施類型**不限於下表**，可依內容需求自由擴充新類型，只要延續「一間廢棄的 GK 公司/關聯設施，長出失控扭曲樣貌」的邏輯即可，甚至有時可遭遇「還在正常運作的 GK 公司設施（例如藥房、流水線工廠、無人商店、包裹理貨中心等等，裡面會有大量功能完整的機器人）」：

| 設施類型 | 原本用途 | 失控後的樣貌 |
| --- | --- | --- |
| 補給設施 | GK 公司的物流/倉儲中心，存放 GkBot 零件與民生物資 | 自動販賣/補給系統仍在運作但邏輯錯亂，是「商店」「寶箱」節點的主要場景 |
| 研究設施 | 研發 GkBot 與相關量產技術的實驗室 | 殘留的實驗性強化裝置、未知藥劑仍在自動運作，是「祝福（Blessing）」節點的主要場景 |
| 維修設施 | GkBot 的保養/維修中心 | 殘存的維修型 GkBot 與失控機具在此徘徊，是「怪物（Monster）」節點常見場景 |
| 虛擬實境設施 | 原本用於 GkBot 表演型/教育型的模擬訓練場 | 現實與模擬邊界崩壞，環境會出現不合理的扭曲景象，是「輪盤（Roulette）／事件」節點的主要場景，也是「異世界感」最強烈的地方 |
| 工廠 | GkBot 零組件/量產線的重工業廠房 | 產線仍在空轉，機械臂與半成品 GkBot 在黑暗中持續作業，是大量「維修型/失控搬運」怪物的密集場景 |
| 娛樂場所 | GK 公司員工福利設施（賭場、KTV、遊樂園等） | 聲光效果與賭博機具仍失控運轉，是「輪盤／事件」節點的另一種變體場景，投機者職業在此特別如魚得水 |
| 百貨商場 | GK 集團旗下的零售通路，販售民生用品與 GkBot 周邊 | 貨架與結帳系統仍自動運作但邏輯錯亂，是「寶箱」「商店」節點的另一種變體場景 |
| 小賣店 | 街角的小型補給站/便利商店 | 規模最小、最貼近一般倖存者生活圈的入口設施，物資稀少但風險也相對較低 |

這張對照表可以直接作為未來設計節點視覺風格、場景文案、甚至怪物/道具命名的素材庫——不需要另外發明一套「異世界」美術語言，全部都能合理地從「一間廢棄的 GK 公司設施」長出來。

## 3. 設施風險與敵對陣營的故事邏輯

> 機制、數值曲線、機率公式等定案內容見 `enemy-factions-and-severity` change 的 spec。

每個 GK 設施除了「類型」（第 2 節）之外，還有各自的毀損/運作程度之分——這決定了裡面殘存的威脅是「機械」還是「人類」。核心敘事邏輯：**設施越接近仍在運作的狀態，裡面的 GkBot 就越多、越可能出現強敵；越是深度荒廢的設施，殘存的機械威脅越少，但心懷不軌的人類或合成人的存在感反而會提高**——荒廢程度與「機械 vs 人類」的敵人組成比例是兩條獨立但相關的光譜。

- **GkBot 殘部**：浩劫的直接產物，失控/叛變的量產機器人，是這些設施裡最主要、最常見的敵人陣營
- **人類/合成人（末世盜賊團）**：部分設施會被人類勢力（掠奪者、幫派、私兵）或身分不明的合成人佔領、盤據。浩劫之後法治蕩然無存，這批人並非只針對 GkBot 復仇或求生——他們同樣把落單、勢弱的其他倖存者當成獵物。對他們來說，「佔領一座 GK 設施」本身就是雙重生意：一邊利用設施裡殘存的資源與地利對抗/躲避 GkBot，一邊伏擊、洗劫任何誤闖或路過的倖存隊伍。玩家在這些設施裡遇到人類/合成人陣營時，本質上就是撞見了正在打劫其他倖存者地盤的末世盜賊團——他們不是「反抗軍」或「另一群受害者」，而是把末日廢墟當成弱肉強食獵場的加害者，這也是「深度荒廢設施反而人為威脅更難預測」的敘事理由：機械威脅少，不代表安全，只是換一種掠奪者當道。

## 4. 玩家角色的秘密（⚠️ 僅限暗示）

延續「裝備＝外部工具、身體＝逐漸機械化」的敘事對比，`gkbot-adventure-run` 把這個設定往前推一步：**倖存者在這些設施裡進出多次後，身體已經局部機械化，但自己完全沒有意識到這件事**。這件事只能透過**機制與道具文案的細節**讓玩家自己起疑，絕不能有任何文案直接點破。

### 4.1 藥水（機油）

> 五級稀有度的完整文案定案內容見 `items-and-equipment` change 的 `ITEM_TEMPLATES` 資料。

道具圖示與名稱維持「藥水」不變（icon、in-game 顯示名稱都正常呈現為治療類消耗品），但**物品描述文案**要讓玩家自己讀出違和感。範例基調：

> 「為什麼我喝機油會補血...？但真好喝，咕嚕咕嚕咕嚕。」

寫作原則：
- 角色**明確感到疑惑**（「為什麼喝機油會有效」），製造認知失調
- 但角色**毫不抗拒、甚至覺得好喝**，暗示身體已經「認得」這種物質，而非單純黑色幽默的硬吞
- 全程不解釋原因，把懸念留給玩家；隨稀有度等級，語氣可從「單純疑惑」逐步走向「隱約自我懷疑但仍不明講」，最高階也只能讓角色「差一步就要意識到」，絕不能替角色說出「我是機械人」這類明確結論

### 4.2 其他可延伸的暗示點（非本次必做，供未來設計參考）

| 遊戲內顯示的樣子 | 暗示手法 |
| --- | --- |
| 商店/拾荒能用零件、螺絲釘之類的雜物交易 | 角色台詞可以是「這種破銅爛鐵他們也收？」但商人真的收了，且給的報酬不差 |
| 工匠 Tinkerer 的核心特色「Salvage」 | 角色描述可以強調他「莫名其妙就是知道怎麼修」，而非「因為他學過工程」——技能來源本身就帶點違和感，也是全職業中最接近察覺真相的人 |
| 祝福（Blessing）節點的增益 | 效果描述可以是身體的變化感（發熱、震動、金屬味），而不是傳統奇幻的光芒/神聖感 |

## 5. 5 個職業（archetype）的世界觀定錨

> 各職業的屬性/機制定案內容見 `redesign-character-archetypes` change 的 spec。

延續 `character-design.md` 已定案的 5 個職業，他們並非「被傳送到異世界」，而是**同一場末日浩劫下，走上不同求生路線的倖存者**，各自帶著末日前的職業技能踏入這些廢棄設施討生活（運動員/健身者、背包客/旅行者、學生/研究員、工程師/Maker、業務/上班族）。如第 4.2 節所述，工匠 Tinkerer 是刻意設計成「敘事上最靠近真相」的角色，投機者 Gambler 則作為對照組保留敘事透氣空間，與機械化真相無關。

## 6. Roguelike Run 的故事骨架：章節・關卡・Run・Stage

> 章節/關卡/Run/Stage 的具體結構、設施主題輪替、結算規則定案內容見 `adventure-run-core`、`adventure-stage-progression`、`single-stage-run-settlement`、`combat-engine`、`events-and-blessings` 等 change 的 spec；本節只定案敘事層級的世界觀骨架。

一趟**章節（Chapter）＝攻略單一 GK 設施**：同一個設施主題（第 2 節）會依其規模/複雜度切成數量不等的**關卡（Level）**——小型設施（例如小賣店）關卡少，大型/複雜設施（例如研究設施）關卡多，象徵設施本身的規模差異，而非單純的難度數字。每個關卡＝**一次 run**：深入設施一段，靠戰鬥、拾荒、意外的機緣一路推進，直到擊敗這段路上的頭目——關卡攻略成功，這趟遠征就告一段落；一個章節的所有關卡都攻略完，才代表這座設施真正被摸透，下一次遠征會換成下一個設施主題重新開始。沒有「通關整個遊戲」的終局，但每一趟遠征、每一個關卡本身都有明確的成功/失敗結局。

一次 run 內部由一串**場景（Stage）**串接：戰鬥、祝福或詛咒、輪盤、休息……等各種遭遇交錯出現，最後固定以一場頭目戰收尾。戰鬥場景的敵人可能分 1~2 波次現身，每波最多 3 名雜兵；頭目戰通常會有 2 名小兵隨侍在側，部分頭目甚至會在手下出現空缺時就地補充新的小兵——呼應「這裡的失控系統/幫派勢力還在持續運作、不是坐以待斃」的敘事基調。

**核心敘事張力**：拾荒有風險，活著出來才算數。深入設施途中撿到的資源，只有平安帶出來才會真正收進倖存者的口袋；中途陣亡或失聯，這趟斬獲就全部遺留在設施裡，倖存者靠著這趟累積的經驗活了下來，下次仍會回到同一個關卡再闖一次——象徵這一段還沒被真正摸透。

## 7. 怪物陣營對照的故事邏輯

> GkBot 陣營與末世盜賊團陣營各自完整的小兵/頭目命名、數值傾向定案內容見 `enemy-factions-and-severity` change 的 spec。

呼應第 3 節「機械 vs 人類/合成人」的陣營光譜，兩邊各自準備獨立的小兵與頭目命名/風味，讓「同一個功能定位，機械 or 人類會給出不同答案」這件事有明確參照：機械頭目走「機械蠻力/自動化系統」路線，人類頭目走「指揮官/財庫」等人類化路線，兩邊刻意不共用同一套定位語彙。

### 7.1 帶技能的敵人（概念定案，機制留給 `enemy-boss-skills` change）

技能不限於頭目專屬，未來一般小兵與玩家也可能擁有技能；先從既有名單挑出敘事/機制上最適合帶技能的 8 隻起步（機械 4 + 人類 4，呼應「機械靠自我維持 vs 人類靠意志力爆發」的對比），冷卻等實際機制不在本文件範圍：

| 敵人 | 陣營 | 技能 | 效果概念 |
| --- | --- | --- | --- |
| 核心維修官 | GkBot 頭目 | 自我修復 | 戰鬥中定期回復自身 HP 一定比例，呼應「機械沒有精神力，只有維修週期」 |
| 產線總管 | GkBot 頭目 | 過載攻擊 | 消耗自身少量 HP 換取單次大幅提升的 ATK，體現「失控產線不計後果地運作」 |
| 幻象法師型 | GkBot 頭目 | 幻影分身 | 短時間內大幅提升閃避率，呼應 VR 設施「現實與模擬邊界崩壞」 |
| 商場保全指揮核心 | GkBot 頭目 | 警報連動 | 觸發後小幅強化同場其他敵人的 DEF，呼應「保全系統聯防邏輯仍在運作」 |
| 百夫長 | 盜賊團頭目 | 腎上腺素爆發 | 短時間內大幅縮短行動間隔（等同攻速提升），體現人類靠腎上腺素硬撐 |
| 狂暴幫主 | 盜賊團頭目 | 嗜血狂化 | HP 越低，ATK 加成越高，呼應「困獸之鬥」的人性掙扎 |
| 影武者 | 盜賊團頭目 | 背刺爆擊 | 提升自身下一次攻擊的爆擊率/爆擊倍率，呼應潛行刺客定位 |
| 末路狂人 | 盜賊團頭目 | 自爆終結技 | HP 低於閾值時觸發一次高倍率傷害爆發攻擊（伴隨自身代價），呼應「不成功便成仁」 |

其餘模板本次不帶技能，維持純數值差異；未來若要擴充到一般小兵/玩家技能，可以在 `enemy-boss-skills` change 裡重新評估要不要從這份清單延伸。

## 8. 尚待確認 / 可延伸的敘事缺口

- 第 7.1 節「帶技能的敵人」只定案概念與敘事方向，實際的技能觸發/冷卻機制留待專屬 change（`enemy-boss-skills`）設計，且該機制未來可能延伸到一般小兵與玩家角色
- 是否要讓 Tinkerer 之外的職業也有機會透過特定劇情/隱藏事件察覺真相（例如 Scholar 的 Study 機制長期累積後），目前沒有機制掛鉤，屬於未來可選的敘事擴充
- 侵略型 GkBot 曾暗示的「秘密」與「自毀程式」尚未定案具體內容；若之後要讓這些設施失控扭曲的成因與該秘密相關，需要回頭同步更新相關世界觀文件
