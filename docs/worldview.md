# GkBot Adventure Run 世界觀

> 本文件是內部設計參考文件，供後續 openspec change（`adventure-run-core`、`events-and-blessings`、`items-and-equipment`、`combat-engine`、`redesign-character-archetypes`、`adventure-stage-progression` 等）撰寫敘事文案、道具/怪物命名時對齊使用。
>
> **可公開／玩家可見**：GK 宇宙時間線、GkBot 浩劫、廢棄 GK 公司各類設施——這些是遊戲本身可以明講的世界觀背景，適合用在開場旁白、圖鑑、載入畫面等文案。
> **⚠️ 僅限暗示，禁止明講**：玩家角色自身已局部機械化這件事——只能透過道具描述、機制細節（例如「喝機油回血」）讓玩家自己拼湊/懷疑，任何文案都不可以直接寫出「你已經是半機械人」這類明確陳述。

## 1. 世界觀時間線：GK 宇宙與 GkBot 浩劫（可公開）

沿用 `side projects/logicard-duel` 已確立的世界觀時間線（見該專案 `docs/worldview.md`）：

> 公元 5487 年，GK 公司量產的勞力機器人「GkBot」全面普及，某天無預警開始攻擊人類，短時間內地球人口驟減近 70 億，倖存者四散躲藏。

`gkbot-adventure-run` 與 `logicard-duel` 是**同一場浩劫、不同的求生方式**，這點可以直接寫進遊戲的世界觀文案：
- `logicard-duel`：倖存者靠「向 GkBot 發起邏輯牌決鬥」正面對決，賭命求生
- `gkbot-adventure-run`：倖存者組隊反覆深入 GK 公司散布各地的廢棄設施，進行一次次的探索遠征（roguelike run），靠戰鬥、拾荒、意外的機緣存活下來並帶回資源

## 2. GK 公司的各類廢棄設施（可公開）

遊戲裡的探索場景不是抽象的異空間，而是**具體、寫實的 GK 公司設施群**，浩劫發生後被廢棄、失控、部分區域甚至因失控系統而扭曲變形，早已面目全非、詭異難辨。設施類型**不限於下表**，可依內容需求自由擴充新類型，只要延續「一間廢棄的 GK 公司/關聯設施，長出失控扭曲樣貌」的邏輯即可：

| 設施類型 | 原本用途 | 失控後的樣貌 |
| --- | --- | --- |
| 補給設施 | GK 公司的物流/倉儲中心，存放 GkBot 零件與民生物資 | 自動販賣/補給系統仍在運作但邏輯錯亂，是「商店」「寶箱」節點的主要場景 |
| 研究設施 | 研發 GkBot 與相關量產技術的實驗室 | 殘留的實驗性強化裝置、未知藥劑仍在自動運作，是「祝福（Blessing）」節點的主要場景 |
| 維修設施 | GkBot 的保養/維修中心 | 殘存的維修型 GkBot 與失控機具在此徘徊，是「怪物（Monster）」節點常見場景 |
| 虛擬實境設施 | 原本用於 GkBot 表演型/教育型的模擬訓練場 | 現實與模擬邊界崩壞，環境會出現不合理的扭曲景象，是「輪盤（Roulette）／事件」節點的主要場景，也是「異世界感」最強烈的地方 |
| 工廠 | GkBot 零組件/量產線的重工業廠房 | 產線仍在空轉，機械臂與半成品 GkBot 在黑暗中持續作業，是大量「維修型/失控搬運」怪物的密集場景 |
| 娛樂場所 | GK 公司員工福利設施（賭場、KTV、遊樂園等） | 聲光效果與賭博機具仍失控運轉，是「輪盤／事件」節點的另一種變體場景，投機者職業在此特別如魚得水 |
| 百貨商場 | GK 集團旗下的零售通路，販售民生用品與 GkBot 周邊 | 貨架與結帳系統仍自動運作但邏輯錯亂，是「寶箱」「商店」節點的另一種變體場景 |
| 小賣店 | 街角的小型補給站/便利商店 | 規模最小、最貼近一般倖存者生活圈的入口設施，物資稀少但風險也相對較低 |

這張對照表可以直接作為未來設計節點視覺風格、場景文案、甚至怪物/道具命名的素材庫——不需要另外發明一套「異世界」美術語言，全部都能合理地從「一間廢棄的 GK 公司設施」長出來。

## 3. 設施風險分級與敵對陣營（可公開）

每個 GK 設施除了「類型」（第 2 節）之外，還有一個獨立的**毀損/運作程度分級**，這個分級決定了玩家在裡面會遇到「多少」敵人、敵人「多強」，以及敵人的**陣營**是機械（GkBot 殘部）還是人類/合成人。

### 3.1 分級光譜：從深度荒廢到高度運作

| 分級（示意，非正式命名） | 樣貌 | 敵人數量/強度 |
| --- | --- | --- |
| 深度荒廢／嚴重毀損 | 結構崩塌、動力所剩無幾，多數系統已徹底停擺 | 敵人數量少，多是初階叛變或故障的低等 GkBot；偶爾會遇到零星、心懷不軌的人類掠奪者或身分不明的合成人 |
| 部分運作／殘存動力 | 主結構還在，部分系統仍靠殘存動力運轉 | GkBot 數量與協調性提升，行動模式更接近浩劫前的正常運作；人類蹤跡也更常見，可能是小股佔據者 |
| 高度運作／警戒森嚴 | 幾乎維持浩劫前的運作水準，安防系統仍在戒備 | GkBot 數量多、強度高，出現強敵/頭目機率大幅提升；也是「整批人類武裝勢力佔領」最常發生的分級 |

**核心原則**：設施越接近仍在運作的狀態，裡面的 GkBot 就越多、越可能出現強敵；越是深度荒廢的設施，殘存的機械威脅越少，但相對地，心懷不軌的人類或合成人的存在感會提高——荒廢程度與「機械 vs 人類」的敵人組成比例是兩條獨立但相關的光譜。

### 3.2 敵對陣營：GkBot 殘部 vs 人類/合成人

- **GkBot 殘部**：浩劫的直接產物，失控/叛變的量產機器人，是這些設施裡最主要、最常見的敵人陣營（沿用第 2 節各設施類型的既有怪物風味，例如維修型 GkBot、保全機具）
- **人類/合成人（末世盜賊團）**：並非所有設施都只有機器——部分設施會被人類勢力（掠奪者、幫派、私兵）或身分不明的合成人佔領、盤據，此時該設施（或該設施內特定區域）的小兵與頭目會以人類/合成人為主，而非 GkBot。這類敵人通常出現在：
  - 深度荒廢設施裡零星遊蕩、心懷不軌的個體（機械威脅低，人為威脅反而更難預測）
  - 高度運作設施裡整批佔領該設施的武裝勢力（機械與人為威脅同時存在，難度最高）

  浩劫之後，法治蕩然無存，這批人類敵對勢力並非只針對 GkBot 復仇或求生——他們同樣把落單、勢弱的其他倖存者當成獵物。對他們來說，「佔領一座 GK 設施」本身就是雙重生意：一邊利用設施裡殘存的資源與地利對抗/躲避 GkBot，一邊伏擊、洗劫任何誤闖或路過的倖存隊伍，搶奪物資、裝備甚至補給點的控制權。玩家在這些設施裡遇到人類/合成人陣營時，本質上就是撞見了正在打劫其他倖存者地盤的末世盜賊團——他們不是「反抗軍」或「另一群受害者」，而是把末日廢墟當成弱肉強食獵場的加害者，這也是「深度荒廢設施反而人為威脅更難預測」的敘事理由：機械威脅少，不代表安全，只是換一種掠奪者當道。

**尚待設計**：分級光譜對應的具體數值曲線（敵人數量/強度倍率）、人類/合成人陣營的敵人範本（小兵/頭目命名與數值），以及「設施分級」如何與既有的設施主題/Stage 結構掛鉤，留待專屬 change（例如敵人陣營與設施分級相關 change）設計；本文件先把世界觀決策定案，機制實作不在本節範圍內。

## 4. 玩家角色的秘密：局部機械化（⚠️ 僅限暗示）

延續 `logicard-duel` 「裝備＝外部工具、卡牌＝身體機械化」的敘事對比，`gkbot-adventure-run` 把這個設定往前推一步：**倖存者在這些設施裡進出多次後，身體已經局部機械化，但自己完全沒有意識到這件事**。這件事只能透過**機制與道具文案的細節**讓玩家自己起疑，絕不能有任何文案直接點破。

### 4.1 藥水（機油）—— 最主要的暗示載體

道具圖示與名稱維持「藥水」不變（icon、in-game 顯示名稱都正常呈現為治療類消耗品），但**物品描述文案**要讓玩家自己讀出違和感。範例基調（正式文案可依此發想，不必逐字照搬）：

> 「為什麼我喝機油會補血...？但真好喝，咕嚕咕嚕咕嚕。」

寫作原則：
- 角色**明確感到疑惑**（「為什麼喝機油會有效」），製造認知失調
- 但角色**毫不抗拒、甚至覺得好喝**，暗示身體已經「認得」這種物質，而非單純黑色幽默的硬吞
- 全程不解釋原因，把懸念留給玩家

其他稀有度的藥水可以延伸同一套語氣，例如越高稀有度、角色反應越自然/越上癮（「這瓶...特別香」「怎麼有點想念這個味道」），暗示機械化程度隨劇情/等級推進而加深，但同樣不可明講。

### 4.2 其他可延伸的暗示點（非本次必做，供未來設計參考）

| 遊戲內顯示的樣子 | 暗示手法 |
| --- | --- |
| 商店/拾荒能用零件、螺絲釘之類的雜物交易 | 角色台詞可以是「這種破銅爛鐵他們也收？」但商人真的收了，且給的報酬不差 |
| 工匠 Tinkerer 的核心特色「Salvage」 | 角色描述可以強調他「莫名其妙就是知道怎麼修」，而非「因為他學過工程」——技能來源本身就帶點違和感 |
| 祝福（Blessing）節點的增益 | 效果描述可以是身體的變化感（發熱、震動、金屬味），而不是傳統奇幻的光芒/神聖感 |

## 5. 5 個職業（archetype）在此設定下的重新定位

延續 `character-design.md` 已定案的 5 個職業（沿用其屬性/機制設計，`openspec/changes/redesign-character-archetypes`），世界觀上重新定錨為：他們並非「被傳送到異世界」，而是**同一場末日浩劫下，走上不同求生路線的倖存者**，各自帶著末日前的職業技能踏入這些廢棄設施討生活：

| 職業 | 末日前身分 | 在設施裡看似什麼 | 實際上（⚠️ 僅限暗示） |
| --- | --- | --- | --- |
| 戰士 Fighter | 運動員/健身者 | 身體素質最好，最快適應戰鬥 | 機械化程度最淺，單純靠肉身撐過去 |
| 冒險家 Adventurer | 背包客/旅行者 | 擅長探索、常發現隱藏內容 | 憑本能感知到設施裡「不對勁的地方」往往藏著殘存系統的接口 |
| 學者 Scholar | 學生/研究員 | 靠學習/記錄敵人規律取得優勢 | 下意識在拼湊這些設施的運作邏輯，某種程度上正逼近真相 |
| 工匠 Tinkerer | 工程師/Maker | 靠拾荒零件轉化能力 | **全職業中最接近察覺真相的人**（見 4.2） |
| 投機者 Gambler | 業務/上班族 | 熱愛輪盤、賭博式抉擇 | 純粹的人性本色，與機械化真相無關，作為對照組保留敘事透氣空間 |

Tinkerer 是刻意設計成「敘事上最靠近真相」的角色——如果之後要做角色專屬旁白/隱藏對話，工匠是最適合埋伏筆的職業。

## 6. Roguelike Run 的關卡／節點結構（`adventure-stage-progression` + `single-stage-run-settlement`）

一次 run＝**攻略單一 GK 設施的一趟完整遠征**：進入一個設施主題 → 該設施是一個 Stage（10~20 個節點，最後一個節點固定 Boss 戰）→ 節點依序推進，**Boss 戰勝利即代表這趟遠征攻略成功，run 立即結束並結算**，不會再有「打完接著推進到同一設施更深處的下一關」這種循環；下一趟遠征會換成下一個設施主題重新開始，沒有「通關整個遊戲」的終局，但每一趟遠征本身有明確的成功/失敗結局。

- **設施主題＝角色的持久進度，不是 run 本身的計數器**：依序循環第 2 節列出的設施類型，目前實作（`STAGE_CONFIG.FACILITY_THEMES`）依序對應到 8 個具體設施名稱：補給設施＝「廢棄補給站」、研究設施＝「廢棄研究所」、維修設施＝「廢棄維修廠」、虛擬實境設施＝「崩壞VR體驗館」、工廠＝「廢棄工廠」、娛樂場所＝「荒廢遊樂場」、百貨商場＝「廢棄百貨公司」、小賣店＝「無主小賣店」。這個主題記在倖存者自己身上，只有**攻略成功**（Boss 戰勝利）才會換到下一個設施；中途陣亡或斷線逾時，下次遠征仍是同一個設施主題，等於倖存者決定回頭再闖一次同一個地方
- **Stage＝這趟遠征唯一的關卡**：10~20 個節點，最後一個節點固定是 Boss 戰
- **節點（Node）＝ Stage 內的具體遭遇**：節點可能是戰鬥（1~2 波敵人）、事件、祝福等；戰鬥節點一抵達就會先讓倖存者看清第一波敵人的種類、外觀與簡介（等同「開門看到什麼」的直覺反應），但後續增援波次仍保持未知，維持戰鬥的驚喜感

節點類型對應第 2 節的設施類型（風味參考，不強制每個節點都要嚴格對應當前設施類型）：

- **戰鬥（Monster）**：主要發生在維修設施/工廠，遭遇殘存/失控的維修型 GkBot 與失控機具（外觀可呼應 `logicard-duel` 的工作/表演/侵略/防禦 4 型號分野，後續設計怪物範本時可作為風味參考，不必 1:1 對應）；若該設施依第 3 節分級被人類/合成人佔領，戰鬥節點的敵人改以人類/合成人（末世盜賊團）為主
- **寶箱（Chest）**：主要發生在補給設施/百貨商場/小賣店，拾荒殘留物資，掉落裝備/道具/零件素材
- **祝福（Blessing）**：主要發生在研究設施，殘留的實驗性強化裝置自動運作，玩家體感是神秘力量賜福
- **輪盤（Roulette）／事件**：主要發生在虛擬實境設施/娛樂場所，現實與模擬邊界崩壞下的機緣與風險並存的抉擇點，投機者職業在此節點特別吃香
- **Boss**：這趟遠征的終點，強度與獎勵皆高於一般戰鬥節點，依第 3 節分級決定是機械頭目還是人類/合成人（末世盜賊團）首領；擊敗 Boss＝這趟遠征圓滿落幕

### 6.1 遠征結局：滿載而歸 vs 死裡逃生

倖存者深入設施拾荒，帶不帶得回東西取決於這趟遠征怎麼收場：

- **攻略成功（擊敗 Boss）**：這趟遠征撿到的金幣、寶石、裝備全部正式收進倖存者的永久資源與背包，沿途擊敗的敵人也讓倖存者累積了實戰經驗值——足夠的經驗值會讓倖存者變得更強（升級、獲得可分配的屬性點）。設施主題也在此刻切換到下一個，象徵這個地方已經被摸透，該找下一個目標了。
- **中途陣亡或失聯（斷線逾時）**：倖存者這趟深入設施的所有斬獲——金幣、寶石、沿途撿到的裝備——全部遺留在設施裡，帶不出來；唯一能確定留下的，是這趟遠征累積的實戰經驗值，倖存者靠著這些經驗活了下來（或被同伴救回），下次仍會回到同一個設施重新挑戰。

這個「拾荒有風險、活著出來才算數」的收場方式，呼應第 1 節「靠戰鬥、拾荒、意外的機緣存活下來並帶回資源」——資源要真的**帶回來**才算數，這也是遠征的核心張力所在。
