# enemy-factions-and-severity

Facility severity tiers (wreck level -> enemy density/strength, chance scaling with a character's chapterIndex) and enemy factions (GkBot vs human/synthetic-human occupiers), rolled once per run on top of single-stage-run-settlement; expands the enemy roster to 32 named templates (8 mobs + 8 bosses per faction) with per-archetype crit/dodge overrides
